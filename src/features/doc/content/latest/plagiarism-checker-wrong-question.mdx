Proctorio published a piece on the reasoning behind **Author Proof**, the
Canvas-integrated integrity tool I designed end-to-end.

The argument is the one the project was built on: plagiarism and AI-writing
detectors analyze the _document_, not the _student_. They answer "Is this
original?", a question a paraphrase, an AI rewrite, or a ghostwriter can all
pass. The question worth asking is "Did you write this?", and answering it takes
comprehension, not similarity scoring.

Justin Depuydt wrote it for Proctorio. My side of the project is in the
[Author Proof case study](/work/author-proof).
