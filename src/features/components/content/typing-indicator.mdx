A typing indicator says who's writing a reply in a conversation. It names up
to three people, then says "Several people are typing…". It leaves out the
person looking at the screen, and keeps its height when nobody is typing, so
the messages above it don't jump.

<ExhibitCode label="Usage">

```tsx
import {
  TypingIndicator,
  type TypingPerson,
} from "@/components/ui/typing-indicator"

export function Channel({
  typing,
  me,
}: {
  typing: TypingPerson[]
  me: string
}) {
  return (
    <>
      <MessageList />
      <TypingIndicator people={typing} currentUserId={me} />
      <Composer />
    </>
  )
}
```

Pass everyone your typing events report, yourself included, and let the
component leave you out. Drop a person once their typing event expires, which
is 10 seconds on Discord.

</ExhibitCode>
<ExhibitCode label="Props">

| Prop            | Type                                   | Default        | Description                                                               |
| --------------- | -------------------------------------- | -------------- | ------------------------------------------------------------------------- |
| `people`        | `TypingPerson[]`                       |                | Everyone typing right now. Pass the current person too; they're left out. |
| `currentUserId` | `string`                               |                | The person looking at the screen, who never sees themselves typing.       |
| `maxNames`      | `number`                               | `3`            | How many people to name before switching to "Several people".             |
| `maxNameLength` | `number`                               | `24`           | Characters a name may take on screen before it's cut short. At least 2.   |
| `format`        | `(sentence: TypingSentence) => string` | `formatTyping` | Builds the sentence. Swap it to translate; the default is English.        |
| `locale`        | `string`                               | `"en"`         | Locale for joining names, passed to `Intl.ListFormat`.                    |
| `announceDelay` | `number`                               | `1500`         | Milliseconds the sentence must hold still before screen readers hear it.  |

It also takes every prop of a `div`, except `children`.

```ts
type TypingPerson = {
  id: string
  name: string
  indicator?: React.ReactNode // replaces the dots while they're the only one typing
}

type TypingSentence = {
  count: number // everyone typing, the current person left out
  names: string[] // empty once count passes maxNames
  list: string // names joined for the locale, such as "Ana, Ben, and Cy"
}
```

</ExhibitCode>
</Exhibit>

    "Name at most three people. Past that, a list of names is harder to read than a count.",

### Translating it

`format` gets `{ count, names, list }` and returns the whole sentence. Never
build it from fragments like `name + " and " + other`: Russian and Polish have
four plural forms, Arabic six and Japanese one, and the verb and the word order
change with them. Write one sentence per case, as an ICU message for instance:

```text
{count, plural,
  =0 {}
  one {{list} is typing…}
  other {{list} are typing…}
}
```

with a separate message for "Several people are typing…" when `names` is
empty. Pass the same `locale` the messages use, so the names are joined in that
language.

## Accessibility

There's nothing to focus: the indicator only reports, so it never enters the
tab order.
