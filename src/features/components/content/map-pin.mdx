Map pin marks a point on a map as a dot, an icon or a labeled pill, and
opens a preview card when you click or tap it. It brings no map of its own:
your map library places it and moves it as the map pans and zooms. The map
here is a stand-in drawn with the site's colors.

<Exhibit
  of="map-pin.Default"
  title="Map pin"
  description="Hover the dot, then click it. The card grows out of the pin."
>
<ExhibitCode label="Install">

```bash
npx shadcn@latest add https://fibo.toribryan.com/r/map-pin.json
```

It installs `@base-ui/react` for the popover, plus the status colors and
their `-subtle` tints a stock theme lacks. Your map library is your own
dependency.

</ExhibitCode>
<ExhibitCode label="Usage">

```tsx
import Map, { Marker } from "react-map-gl/maplibre"

import { MapPin } from "@/components/ui/map-pin"

export function Places({ places }: { places: Place[] }) {
  return (
    <Map initialViewState={{ longitude: -122.42, latitude: 37.77, zoom: 13 }}>
      {places.map((place) => (
        <Marker key={place.id} longitude={place.lng} latitude={place.lat}>
          <MapPin
            label={place.name}
            meta={place.category}
            title={place.name}
            description={place.summary}
          />
        </Marker>
      ))}
    </Map>
  )
}
```

`label` names the pin for screen readers, so give every pin one, even
when it shows a price.

</ExhibitCode>
<ExhibitCode label="Props">

| Prop               | Type                                                             | Default      | Description                                                               |
| ------------------ | ---------------------------------------------------------------- | ------------ | ------------------------------------------------------------------------- |
| `label`            | `string`                                                         |              | The place's name: the accessible name, and a label pin's text by default. |
| `type`             | `"dot" \| "icon" \| "label"`                                     | `"dot"`      | A small point, a round pin with an icon, or a pill with text.             |
| `variant`          | `"default" \| "success" \| "warning" \| "info" \| "destructive"` | `"default"`  | What the color says, when it says something.                              |
| `icon`             | `ReactNode`                                                      | map-pin icon | The icon of an icon pin, or a leading icon in a label pin.                |
| `text`             | `ReactNode`                                                      |              | What a label pin shows when it differs from `label`, such as "$120".      |
| `size`             | `"sm" \| "default"`                                              | `"default"`  | `sm` for dense maps.                                                      |
| `image`            | `{ src: string; alt: string }`                                   |              | A photo at the top of the preview.                                        |
| `meta`             | `ReactNode`                                                      |              | A small line above the title, such as a category or distance.             |
| `title`            | `ReactNode`                                                      |              | The preview's heading.                                                    |
| `description`      | `ReactNode`                                                      |              | A line or two under the title.                                            |
| `children`         | `ReactNode`                                                      |              | Anything else for the preview, under the other fields.                    |
| `open`             | `boolean`                                                        |              | Whether the preview is open, when controlled.                             |
| `defaultOpen`      | `boolean`                                                        |              | Whether it starts open, when uncontrolled.                                |
| `onOpenChange`     | `(open: boolean) => void`                                        |              | Called when the preview opens or closes.                                  |
| `side`             | `"top" \| "right" \| "bottom" \| "left"`                         | `"top"`      | Where the preview opens. It flips when there's no room.                   |
| `previewClassName` | `string`                                                         |              | Classes for the preview, which is portalled to the body.                  |

</ExhibitCode>
</Exhibit>

## Anatomy

A button on the map, and a card portalled to the body so no map container
clips it. The card only renders when there's something to preview.

<Exhibit of="map-pin.Anatomy" title="The card" description="Held open over its pin.">
<ExhibitCode label="Structure">

```text
MapPin               map-pin
└─ preview              map-pin-preview         (while open, portalled)
   ├─ image             map-pin-image
   ├─ meta              map-pin-meta
   ├─ title             map-pin-title
   ├─ description       map-pin-description
   └─ content           map-pin-content         (your children)
```

</ExhibitCode>

  guidelines={[

### Actions in the card

Children go under the other fields, for actions such as directions or saving
the place. The card stays open until you close it, so it can hold them.

<Exhibit of="map-pin.CustomContent" description="Click the dot to see the buttons.">
<ExhibitCode>

```tsx
<MapPin label={place.name} title={place.name} description={place.summary}>
  <Button size="sm">Directions</Button>
  <Button size="sm" variant="outline">
    Save
  </Button>
</MapPin>
```

</ExhibitCode>
</Exhibit>

### With a list beside the map

`open` and `onOpenChange` let a list choose the open pin. Picking a row
opens its card; opening a pin selects its row.

<Exhibit of="map-pin.Controlled" description="Pick a place, or click a dot.">
<ExhibitCode>

```tsx
const [openId, setOpenId] = useState<string | null>(null)

<MapPin
  label={place.name}
  title={place.name}
  open={openId === place.id}
  onOpenChange={(open) => setOpenId(open ? place.id : null)}
/>
```

</ExhibitCode>
</Exhibit>

## Accessibility

| Key                              | Does                                              |
| -------------------------------- | ------------------------------------------------- |
| <Kbd>Tab</Kbd>                   | Moves between the pins                            |
| <Kbd>Space</Kbd> or <Kbd>↵</Kbd> | Opens the preview and moves focus into it         |
| <Kbd>Esc</Kbd>                   | Closes the preview and puts focus back on the pin |
