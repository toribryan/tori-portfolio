A Cmd+K palette for moving around an app and running actions. Items can open
pages of their own, the commands you ran last come first, a search ranks
every command across every page, and a side pane previews the highlighted
one.

<ComponentPreview name="command-menu" />

## Features

- **Nested pages.** An item with `items` opens a page instead of running,
  sliding in with a breadcrumb in the search row. Backspace on an empty
  search, the back button or Escape steps out.
- **Recents.** Commands you run float to the top of the first page under
  Recent, labelled with the page they live on. `storageKey` keeps them across
  visits.
- **Ranked search.** From the first page, a search reaches into every page.
  Whole-label matches rank first, then label starts, word starts, anywhere in
  the label, then keywords, with recent commands nudged up. The matched
  letters are bold.
- **Preview pane.** Items with a `preview` open a pane beside the list that
  follows the highlight. Below the `sm` breakpoint the pane hides.

## Usage

```tsx
import { useRouter } from "next/navigation"

import {
  CommandMenu,
  type CommandMenuGroup,
} from "@/components/ui/command-menu"

export function AppCommands({ setTheme }: { setTheme: (t: string) => void }) {
  const router = useRouter()
  const groups: CommandMenuGroup[] = [
    {
      label: "Go to",
      items: [
        {
          value: "inbox",
          label: "Inbox",
          onSelect: () => router.push("/inbox"),
        },
      ],
    },
    {
      label: "Actions",
      items: [
        {
          value: "theme",
          label: "Change theme",
          items: [
            {
              value: "light",
              label: "Light",
              onSelect: () => setTheme("light"),
            },
            { value: "dark", label: "Dark", onSelect: () => setTheme("dark") },
          ],
        },
      ],
    },
  ]
  return <CommandMenu groups={groups} storageKey="app-commands" />
}
```

Every `value` must be unique across the whole menu, nested pages included:
recents and ranking find commands by it. An item runs its own `onSelect`,
then the menu's `onSelect` gets the item, and the menu closes.

```ts
type CommandMenuItem = {
  value: string
  label: string
  icon?: React.ReactNode
  shortcut?: string[]
  keywords?: string[]
  disabled?: boolean
  onSelect?: () => void
  items?: CommandMenuItem[] // makes the item a page
  placeholder?: string // the search hint on that page
  preview?: React.ReactNode // shown in the side pane
}
```

Render one command menu per page. Its shortcut listens on the whole
document, so two menus with the same `hotkey` would both open.

## API reference

| Prop             | Type                                     | Default                       | Description                                                                                                                          |
| ---------------- | ---------------------------------------- | ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `groups`         | `CommandMenuGroup[]`                     |                               | The commands, in groups shown in order.                                                                                              |
| `onSelect`       | `(item: CommandMenuItem) => void`        |                               | Called with every command run, after the item's own `onSelect`.                                                                      |
| `open`           | `boolean`                                |                               | Whether the menu is open, when you control it.                                                                                       |
| `defaultOpen`    | `boolean`                                | `false`                       | Whether the menu starts open, when it keeps its own state.                                                                           |
| `onOpenChange`   | `(open: boolean) => void`                |                               | Called when the menu opens or closes.                                                                                                |
| `recent`         | `string[]`                               |                               | Values of recently run commands, newest first, when you control them.                                                                |
| `defaultRecent`  | `string[]`                               | `[]`                          | Recently run values to start with, when the menu keeps its own.                                                                      |
| `onRecentChange` | `(recent: string[]) => void`             |                               | Called with the new list each time a command runs.                                                                                   |
| `maxRecent`      | `number`                                 | `5`                           | How many recent commands to keep and show. `0` turns recents off.                                                                    |
| `storageKey`     | `string`                                 |                               | A localStorage key that keeps recents across visits.                                                                                 |
| `hotkey`         | `string \| null`                         | `"k"`                         | The letter that toggles the menu with Cmd on macOS or Ctrl elsewhere. `null` turns the shortcut off.                                 |
| `trigger`        | `ReactElement \| null`                   |                               | An element that opens the menu, in place of the default search button. It must forward its ref and props. `null` renders no trigger. |
| `placeholder`    | `string`                                 | `"Type a command or search…"` | Hint in the search box on the first page.                                                                                            |
| `emptyText`      | `ReactNode`                              | `"No results found"`          | Shown when a search matches nothing.                                                                                                 |
| `label`          | `string`                                 | `"Command menu"`              | Names the dialog and the search box for assistive technology.                                                                        |
| `labels`         | `Partial<CommandMenuLabels>`             |                               | Wording the menu writes for itself, for translation: `recent`, `results`, `back`, `home`, `noPreview` and `count`.                   |
| `hints`          | `boolean`                                | `true`                        | Whether to show the row of keyboard hints under the list.                                                                            |
| `container`      | `HTMLElement \| ShadowRoot \| RefObject` |                               | Where the dialog portals to. Defaults to the body.                                                                                   |
| `className`      | `string`                                 |                               | Classes for the trigger.                                                                                                             |
| `popupClassName` | `string`                                 |                               | Classes for the dialog.                                                                                                              |
