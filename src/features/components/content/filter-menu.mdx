A Filter button whose menu lists the fields you can filter by, then each
field's values. Searching, or just typing, turns the same menu into a search
across every field and value.

<Exhibit
  of="filter-menu.AppliedAsChips"
  title="Filter menu"
  description="Open the menu and tick values. The app shows each applied field as a chip you can remove."
>
<ExhibitCode label="Install">

```bash
npx shadcn@latest add https://fibo.toribryan.com/r/filter-menu.json
```

It installs the Button component and the `motion` package too.

</ExhibitCode>
<ExhibitCode label="Usage">

```tsx
import { useState } from "react"

import {
  FilterMenu,
  type FilterField,
  type FilterValue,
} from "@/components/ui/filter-menu"

const fields: FilterField[] = [
  {
    id: "status",
    label: "Status",
    options: [
      { value: "todo", label: "Todo" },
      { value: "done", label: "Done" },
    ],
  },
  {
    id: "priority",
    label: "Priority",
    options: [
      { value: "urgent", label: "Urgent" },
      { value: "low", label: "Low" },
    ],
  },
]

export function IssueFilters() {
  const [filters, setFilters] = useState<FilterValue>({})
  return (
    <FilterMenu fields={fields} value={filters} onValueChange={setFilters} />
  )
}
```

The menu only picks filters. `value` holds the chosen values keyed by field
id, such as `{ status: ["todo"] }`, and showing the applied filters is up to
your app.

</ExhibitCode>

## Anatomy

The trigger opens a popup with a header row and a list. What the header and
the list hold changes with the view: the fields, one field's values, or a
search.

### Applied as chips

The menu only picks filters. Here the app shows each applied field as a chip

  priority: ["urgent"],

<FilterMenu fields={fields} value={value} onValueChange={setValue} />

))}

### Your own trigger and wording

Any button can open the menu, such as an icon button in a crowded toolbar.
Every piece of text the menu writes can be replaced, for another language.

<Exhibit of="filter-menu.IconTrigger" description="An icon button that opens the same menu.">
<ExhibitCode label="Trigger">

```tsx
<FilterMenu
  fields={fields}
  trigger={
    <Button variant="outline" size="icon-sm" aria-label="Filter">
      <ListFilterIcon />
    </Button>
  }
/>
```

The trigger must forward its ref and props, as fibo's `Button` does.

</ExhibitCode>
<ExhibitCode label="Wording">

```tsx
<FilterMenu
  fields={fields}
  trigger={<Button variant="ghost" size="icon" aria-label="Filtern" />}
  label="Filter"
  searchLabel="Filter durchsuchen"
  emptyText="Keine passenden Filter"
  labels={{
    backToFields: "Zurück zu den Feldern",
    backToFilters: "Zurück zu den Filtern",
    backToField: (field) => `Zurück zu ${field}`,
    results: (count) => `${count} ${count === 1 ? "Ergebnis" : "Ergebnisse"}`,
  }}
/>
```

`open`, `defaultOpen` and `onOpenChange` open it from elsewhere, such as a
keyboard shortcut. `side`, `align` and `container` place the popup.

</ExhibitCode>
</Exhibit>

## Accessibility

Everything works from the keyboard, one level at a time.

| Key                                           | Does                                                              |
| --------------------------------------------- | ----------------------------------------------------------------- |
| <KbdGroup><Kbd>↑</Kbd><Kbd>↓</Kbd></KbdGroup> | Moves the highlight                                               |
| <Kbd>→</Kbd>                                  | Opens the highlighted field                                       |
| <Kbd>↵</Kbd>                                  | Opens the highlighted field, or ticks the highlighted value       |
| Any letter                                    | Starts a search with that letter                                  |
| <KbdGroup><Kbd>←</Kbd><Kbd>⌫</Kbd></KbdGroup> | With no search text, goes back to the fields or leaves the search |
| <Kbd>Esc</Kbd>                                | Clears the search, then leaves the field, then closes the menu    |
| <Kbd>Tab</Kbd>                                | Moves between the list and the Search filters button              |
