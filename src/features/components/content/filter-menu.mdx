A filter button whose menu lists the fields you can filter by, then each
field's values. A Search filters button, or just typing, slides the same menu
over to a search across every field and value, like a command menu.

<ComponentPreview name="filter-menu" />

## Features

- Two levels: pick a field such as Status, then tick any number of its
  values. Each field shows how many of its values are on.
- A Search filters button at the top slides the menu over to a search,
  grouped by field, with the matching letters in bold. Typing a letter on the
  menu does the same. Inside a field, the search stays within it.
- Or, with `search="inline"`, a search box sits at the top instead, and
  typing turns the menu into results in place.
- Escape steps back: first it clears the search, then it leaves the field,
  and only then does it close the menu.
- Views slide forward and back, and the popup's height follows its content.
  Under reduced motion, views swap in place.

## Usage

```tsx
import { useState } from "react"

import {
  FilterMenu,
  type FilterField,
  type FilterValue,
} from "@/components/ui/filter-menu"

const fields: FilterField[] = [
  {
    id: "status",
    label: "Status",
    options: [
      { value: "todo", label: "Todo" },
      { value: "done", label: "Done" },
    ],
  },
  {
    id: "priority",
    label: "Priority",
    options: [
      { value: "urgent", label: "Urgent" },
      { value: "low", label: "Low" },
    ],
  },
]

export function IssueFilters() {
  const [filters, setFilters] = useState<FilterValue>({})
  return (
    <FilterMenu fields={fields} value={filters} onValueChange={setFilters} />
  )
}
```

The menu only picks filters. `value` holds the chosen values keyed by field
id, such as `{ status: ["todo"] }`, and showing the applied filters is up to
your app.

```ts
type FilterField = {
  id: string
  label: string
  icon?: React.ReactNode
  options: { value: string; label: string; icon?: React.ReactNode }[]
}

type FilterValue = Record<string, string[]>
```

### Fitting it into your app

The menu works on its own, and each of these props lets you take over one
part of it:

- `open`, `defaultOpen` and `onOpenChange` put the open state in your hands,
  for a keyboard shortcut or a menu that opens from elsewhere.
- `trigger` swaps the default button for your own element. It must forward its
  ref and props, as fibo's `Button` does.
- `side` and `align` place the popup, and `container` portals it somewhere
  other than the body, such as inside a dialog.
- `popupClassName` styles the popup, which is portalled out of reach of
  selectors on the trigger.
- `labels` replaces the wording the menu writes for itself, alongside
  `triggerLabel`, `placeholder`, `emptyText`, `label` and `searchLabel`.

```tsx
<FilterMenu
  fields={fields}
  trigger={<Button variant="ghost" size="icon" aria-label="Filtern" />}
  label="Filter"
  searchLabel="Filter durchsuchen"
  emptyText="Keine passenden Filter"
  labels={{
    backToFields: "Zurück zu den Feldern",
    backToFilters: "Zurück zu den Filtern",
    backToField: (field) => `Zurück zu ${field}`,
    results: (count) => `${count} ${count === 1 ? "Ergebnis" : "Ergebnisse"}`,
  }}
/>
```

## Examples

### Applied as chips

The component only picks filters. Here the app shows each applied field as a
chip beside the button, with a button to remove it.

<Example of="filter-menu.AppliedAsChips" />

### Default

The menu on its own, keeping its own state. The Search filters button
slides the whole menu, header and body, over to the search state, which
lists every value until you type. Back, Escape or Backspace slides it home.

<Example of="filter-menu.Default" />

### Inline search

`search="inline"` keeps a search box at the top of the menu. Typing turns it
into results in place, and clearing the text brings the menu back.

<Example of="filter-menu.InlineSearch" />

### With selections

`defaultValue` starts with values chosen. The fields that have any show a
count. The trigger's content is yours, here with a dot to say filters are on.

<Example of="filter-menu.WithSelections" />

### Keyboard only

Opened from the keyboard: arrows move, Right opens a field, Enter ticks a
value, and Left or Backspace goes back to the field it came from.

<Example of="filter-menu.KeyboardOnly" />

### No matches

## API reference

| Prop             | Type                                                                       | Default                 | Description                                                                                                                                                                                                                         |
| ---------------- | -------------------------------------------------------------------------- | ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `fields`         | `FilterField[]`                                                            |                         | The fields people can filter by, each with the values it offers.                                                                                                                                                                    |
| `value`          | `FilterValue`                                                              |                         | The chosen values, keyed by field id, when you control the state.                                                                                                                                                                   |
| `defaultValue`   | `FilterValue`                                                              | `{}`                    | The chosen values to start with, when the menu keeps its own state.                                                                                                                                                                 |
| `onValueChange`  | `(value: FilterValue) => void`                                             |                         | Called with every field's chosen values each time one is toggled.                                                                                                                                                                   |
| `triggerLabel`   | `ReactNode`                                                                | `"Filter"`              | What the trigger button says.                                                                                                                                                                                                       |
| `placeholder`    | `string`                                                                   | `"Filter by…"`          | Hint in the inline search box while the field menu is showing.                                                                                                                                                                      |
| `emptyText`      | `ReactNode`                                                                | `"No matching filters"` | Shown when a search matches nothing.                                                                                                                                                                                                |
| `label`          | `string`                                                                   | `"Filters"`             | Names the popup for assistive technology.                                                                                                                                                                                           |
| `searchLabel`    | `string`                                                                   | `"Search filters"`      | Names the search box for assistive technology.                                                                                                                                                                                      |
| `labels`         | `Partial<FilterMenuLabels>`                                                |                         | Wording the menu writes for itself, for translation: `backToFields`, `backToFilters`, `backToField` and `results`.                                                                                                                  |
| `open`           | `boolean`                                                                  |                         | Whether the menu is open, when you control it.                                                                                                                                                                                      |
| `defaultOpen`    | `boolean`                                                                  | `false`                 | Whether the menu starts open, when it keeps its own state.                                                                                                                                                                          |
| `onOpenChange`   | `(open: boolean) => void`                                                  |                         | Called when the menu opens or closes.                                                                                                                                                                                               |
| `side`           | `"top" \| "bottom" \| "left" \| "right" \| "inline-start" \| "inline-end"` | `"bottom"`              | Which side of the trigger the popup opens on. Flips when there's no room.                                                                                                                                                           |
| `align`          | `"start" \| "center" \| "end"`                                             | `"start"`               | Which edge of the trigger the popup lines up with.                                                                                                                                                                                  |
| `container`      | `HTMLElement \| ShadowRoot \| RefObject`                                   |                         | Where the popup portals to. Defaults to the body.                                                                                                                                                                                   |
| `trigger`        | `ReactElement`                                                             |                         | An element to use as the trigger instead of the default button. It must forward its ref and props, as fibo's `Button` does.                                                                                                         |
| `search`         | `"inline" \| "button"`                                                     | `"button"`              | How search starts. `button`, the default, shows a Search filters button at the top, and the menu slides over to its search state when it's used. `inline` keeps a search box there instead, and typing turns the menu into results. |
| `className`      | `string`                                                                   |                         | Classes for the trigger button.                                                                                                                                                                                                     |
| `popupClassName` | `string`                                                                   |                         | Classes for the popup.                                                                                                                                                                                                              |
