Sticker avatar is an avatar cut out like a die-cut sticker. A white paper edge
follows the shape of a transparent image, each sticker sits at its own slight
angle, and status is a small sticker of its own on the corner.

<Exhibit
  of="sticker-avatar.Default"
  title="Sticker avatar"
  description="Hover it. The sticker lifts off the page, and the dot on its corner says Bonzo is here."
>
<ExhibitCode label="Install">

```bash
npx shadcn@latest add https://fibo.toribryan.com/r/sticker-avatar.json
```

It adds `--sticker-edge` and `--sticker-ink` to your theme, and uses the
`success` and `warning` tokens for status.

</ExhibitCode>
<ExhibitCode label="Usage">

```tsx
import { StickerAvatar } from "@/components/ui/sticker-avatar"

export function Member({ user }: { user: User }) {
  return (
    <StickerAvatar
      name={user.name}
      src={user.cutoutUrl}
      status={user.status}
      size={40}
    />
  )
}
```

Pass an image with its background already removed. Cutting a subject out in
the browser takes a 40 to 170 MB model, so do it once on upload, on a server,
or let people bring their own. Images on another host need CORS headers for
the edge to be cut; without them the sticker falls back to round.

</ExhibitCode>
<ExhibitCode label="Props">

| Prop          | Type                               | Default  | Description                                                                           |
| ------------- | ---------------------------------- | -------- | ------------------------------------------------------------------------------------- |
| `name`        | `string`                           |          | Their accessible name, the seed for the tilt, and the initials when there's no image. |
| `src`         | `string`                           |          | A transparent cut-out gets a die-cut edge; a photo with a background becomes round.   |
| `size`        | `number`                           | `40`     | Width and height in pixels. The edge and tilt are drawn outside this box.             |
| `edge`        | `number`                           |          | Paper edge in pixels. Defaults to one sixteenth of the size, never under 2px.         |
| `status`      | `"present" \| "away" \| "offline"` |          | Shows a status sticker on the corner, told apart by shape.                            |
| `statusLabel` | `string`                           |          | Overrides the status's spoken label, for translation.                                 |
| `statusColor` | `boolean`                          | `true`   | Colors the status with the status tokens. Off, it's drawn in the foreground color.    |
| `tilt`        | `boolean \| number`                | `true`   | A stable angle from the name, a number of degrees, or straight.                       |
| `lift`        | `boolean`                          | `true`   | Lifts on hover, and when hovering an ancestor with `group/sticker`.                   |
| `cutout`      | `"auto" \| "shape" \| "round"`     | `"auto"` | Follows the image's own shape when its border is clear, or forces one.                |
| `pixelated`   | `boolean`                          | `false`  | Keeps hard pixel edges when scaling pixel art.                                        |

</ExhibitCode>
</Exhibit>

## Anatomy

A square layout box named as an image. The cut is drawn once on a canvas when
the image loads, then shown as a plain image past the box's edges.

### In a list

At 32px the edge and tilt are small enough for a dense list. Each row carries
`group/sticker`, so hovering anywhere on it lifts the sticker.

<Exhibit of="sticker-avatar.DirectMessages" description="Hover a row. Its sticker lifts.">
<ExhibitCode>

```tsx
<button className="group/sticker flex items-center gap-3.5">
  <StickerAvatar
    aria-hidden="true"
    name={person.name}
    size={32}
    status="away"
  />
  <span>{person.name}</span>
</button>
```

</ExhibitCode>
</Exhibit>

### Tokens

`--sticker-edge` is white and `--sticker-ink` is near-black in both themes.
That's deliberate: a sticker is paper, and paper doesn't change color when the
room gets dark. A hairline and a shadow keep the white edge visible on a light
page.

The status sticker is the exception. Its disc is the page color, because it's
colored with the status tokens: `success` for present, `warning` for away and
`muted-foreground` for offline. Set `statusColor={false}` to draw the marks
in the foreground color instead.
