Token flow shows a color moving through the token tiers, from raw value to
primitive to semantic role.

<ComponentPreview name="token-flow" />

Switch the site theme: rows with a dark pair scramble to their dark
values while the semantic name stays put.

## Features

- One row per role: the raw value, the primitive and the semantic role, joined
  by wires.
- A pulse runs along each wire while the plate is on screen.
- Rows with a `dark` pair scramble to their dark values when the theme changes,
  while the role's name stays put.
- `showUse` prints what each role is for under its chip.

## Installation

<Install name="token-flow" exports={["TokenFlow", "type TokenRow"]} />

No animation library: the pulse and the scramble use the Web Animations API and
`requestAnimationFrame`.

## Usage

```tsx
import { TokenFlow } from "@/components/ui/token-flow"

export function PrimaryToken() {
  return (
    <TokenFlow
      rows={[
        {
          base: "oklch(0.205 0 0)",
          primitive: "neutral-900",
          semantic: "bg-primary",
          dark: { base: "oklch(0.985 0 0)", primitive: "neutral-50" },
        },
      ]}
    />
  )
}
```

Name the role the way people write it in code, and add a `dark` pair when the
role resolves differently in the dark theme.

## API reference

Each row takes a `base` value, a `primitive` name and a `semantic` role, plus
an optional `use` and a `dark` pair for roles that resolve differently in the
dark theme.

| Prop      | Type                | Default | Description                                                                                  |
| --------- | ------------------- | ------- | -------------------------------------------------------------------------------------------- |
| `rows`    | `TokenRow[]`        | —       | Required. One row per role: `base`, `primitive`, `semantic`, plus optional `use` and `dark`. |
| `showUse` | `boolean`           | `false` | Print each row's `use` under its semantic chip.                                              |
| `theme`   | `"light" \| "dark"` | —       | Force a theme instead of following the document's `dark` class.                              |

#### TokenRow

| Field       | Type                                  | Description                                                                          |
| ----------- | ------------------------------------- | ------------------------------------------------------------------------------------ |
| `base`      | `string`                              | The raw value, as written in CSS.                                                    |
| `primitive` | `string`                              | The primitive it is named as, e.g. a palette step.                                   |
| `semantic`  | `string`                              | The semantic role that points at the primitive.                                      |
| `use`       | `string`                              | What the role is for, shown under the semantic chip when `showUse` is set.           |
| `dark`      | `{ base: string; primitive: string }` | The value and primitive the role resolves to under the dark theme, when they differ. |
