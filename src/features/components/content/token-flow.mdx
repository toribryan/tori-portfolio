Token flow shows how a color becomes a design token: the raw value, the
palette step that names it, and the role people use in code. Switch the site
theme and the values change underneath while the role's name stays put.

<Exhibit
  of="token-flow.WithUse"
  title="Token flow"
  description="Three of fibo's roles, each with what it is for. Switch the site theme to watch them flip."
>
<ExhibitCode label="Install">

```bash
npx shadcn@latest add https://fibo.toribryan.com/r/token-flow.json
```

It installs the part on its own. No animation library: the pulse and the
scramble use the Web Animations API and `requestAnimationFrame`.

</ExhibitCode>
<ExhibitCode label="Usage">

```tsx
import { TokenFlow } from "@/components/ui/token-flow"

export function PrimaryToken() {
  return (
    <TokenFlow
      rows={[
        {
          base: "oklch(0.205 0 0)",
          primitive: "neutral-900",
          semantic: "bg-primary",
          dark: { base: "oklch(0.985 0 0)", primitive: "neutral-50" },
        },
      ]}
    />
  )
}
```

Name the role the way people write it in code, and add a `dark` pair when the
role resolves differently in the dark theme.

</ExhibitCode>
<ExhibitCode label="Props">

| Prop      | Type                | Default | Description                                                                                  |
| --------- | ------------------- | ------- | -------------------------------------------------------------------------------------------- |
| `rows`    | `TokenRow[]`        |         | Required. One row per role: `base`, `primitive`, `semantic`, plus optional `use` and `dark`. |
| `showUse` | `boolean`           | `false` | Print each row's `use` under its semantic chip.                                              |
| `theme`   | `"light" \| "dark"` |         | Force a theme instead of following the document's `dark` class.                              |

```ts
type TokenRow = {
  base: string // the raw value, as written in CSS
  primitive: string // the palette step it is named as
  semantic: string // the role that points at the primitive
  use?: string // what the role is for, shown with showUse
  dark?: { base: string; primitive: string } // when the dark theme differs
}
```

</ExhibitCode>
</Exhibit>

## Anatomy

A dotted plate with a label over each tier, and one row per role below.

<Exhibit

<ExhibitCode label="Structure">

```text
TokenFlow                token-flow
├─ tiers                 Base, Primitive, Semantic (decorative)
└─ row                   one per entry in rows
   ├─ chip               token-flow-chip   the value
   ├─ wire               carries the pulse (decorative)
   ├─ chip               token-flow-chip   the primitive
   ├─ wire
   └─ chip               token-flow-chip   the role
      └─ use             with showUse
```

## Variants and states

### Use lines

Rows print what each role is for only when asked. Leave them off for readers
who already know the names.

<Exhibit
  of="token-flow.Default"
  title="Without use"
  description="The default: three chips per row, nothing underneath."
>
<ExhibitCode>

```tsx
<TokenFlow rows={rows} />
```

</ExhibitCode>
</Exhibit>

<Exhibit

### Theme

The plate follows the site theme. When it changes, rows with a dark pair
scramble to their new values and the swatches fade across, while the role
names hold still.

<Exhibit
  of="token-flow.ThemeChange"
  title="Theme change"
  description="Flips between light and dark every few seconds, so the scramble plays."
>
<ExhibitCode>

```tsx

  primitive: "neutral-900",
  semantic: "bg-primary",
  dark: { base: "oklch(0.985 0 0)", primitive: "neutral-50" },
}
```

</ExhibitCode>
</Exhibit>

### Motion

A pulse runs along each wire while the plate is on screen, staggered by row.
It stops off screen, and neither the pulse nor the scramble plays when
someone has asked for reduced motion.

  guidelines={[

### In a themed preview

A preview that owns its own theme can pin the plate to it, so the values
match the components beside them.

<Exhibit
  of="token-flow.InPreview"
  description="Switch the preview between light and dark: the buttons and the plate move together."
>
<ExhibitCode>

```tsx
<div className={dark ? "dark" : "light"}>
  <TokenFlow rows={rows} theme={dark ? "dark" : "light"} />
  <Button>Save changes</Button>
  <Button variant="destructive">Delete</Button>
</div>
```

The class on the wrapper moves the surfaces, and `theme` moves the values.

</ExhibitCode>
</Exhibit>
