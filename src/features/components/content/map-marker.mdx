Map marker marks a point on a map as a dot, an icon or a labelled pill, and
opens a preview card when you click or tap it. It brings no map of its own:
your map library places it and moves it as the map pans and zooms. The map
here is a stand-in drawn with the site's colours.

<Exhibit
  of="map-marker.Default"
  title="Map marker"
  description="Hover the dot, then click it. The card grows out of the marker."
>
<ExhibitCode label="Install">

```bash
npx shadcn@latest add https://fibo.toribryan.com/r/map-marker.json
```

It installs `@base-ui/react` for the popover, plus the status colours and
their `-subtle` tints a stock theme lacks. Your map library is your own
dependency.

</ExhibitCode>
<ExhibitCode label="Usage">

```tsx
import Map, { Marker } from "react-map-gl/maplibre"

import { MapMarker } from "@/components/ui/map-marker"

export function Places({ places }: { places: Place[] }) {
  return (
    <Map initialViewState={{ longitude: -122.42, latitude: 37.77, zoom: 13 }}>
      {places.map((place) => (
        <Marker key={place.id} longitude={place.lng} latitude={place.lat}>
          <MapMarker
            label={place.name}
            meta={place.category}
            title={place.name}
            description={place.summary}
          />
        </Marker>
      ))}
    </Map>
  )
}
```

`label` names the marker for screen readers, so give every marker one, even
when it shows a price.

</ExhibitCode>
<ExhibitCode label="Props">

| Prop               | Type                                                             | Default     | Description                                                                  |
| ------------------ | ---------------------------------------------------------------- | ----------- | ---------------------------------------------------------------------------- |
| `label`            | `string`                                                         |             | The place's name: the accessible name, and a label marker's text by default. |
| `type`             | `"dot" \| "icon" \| "label"`                                     | `"dot"`     | A small point, a round marker with an icon, or a pill with text.             |
| `variant`          | `"default" \| "success" \| "warning" \| "info" \| "destructive"` | `"default"` | What the colour says, when it says something.                                |
| `icon`             | `ReactNode`                                                      | map pin     | The icon of an icon marker, or a leading icon in a label marker.             |
| `text`             | `ReactNode`                                                      |             | What a label marker shows when it differs from `label`, such as "$120".      |
| `size`             | `"sm" \| "default"`                                              | `"default"` | `sm` for dense maps.                                                         |
| `image`            | `{ src: string; alt: string }`                                   |             | A photo at the top of the preview.                                           |
| `meta`             | `ReactNode`                                                      |             | A small line above the title, such as a category or distance.                |
| `title`            | `ReactNode`                                                      |             | The preview's heading.                                                       |
| `description`      | `ReactNode`                                                      |             | A line or two under the title.                                               |
| `children`         | `ReactNode`                                                      |             | Anything else for the preview, under the other fields.                       |
| `open`             | `boolean`                                                        |             | Whether the preview is open, when controlled.                                |
| `defaultOpen`      | `boolean`                                                        |             | Whether it starts open, when uncontrolled.                                   |
| `onOpenChange`     | `(open: boolean) => void`                                        |             | Called when the preview opens or closes.                                     |
| `side`             | `"top" \| "right" \| "bottom" \| "left"`                         | `"top"`     | Where the preview opens. It flips when there's no room.                      |
| `previewClassName` | `string`                                                         |             | Classes for the preview, which is portalled to the body.                     |

</ExhibitCode>
</Exhibit>

## Anatomy

A button on the map, and a card portalled to the body so no map container
clips it. The card only renders when there's something to preview.

<Exhibit of="map-marker.Anatomy" title="The card" description="Held open over its marker.">
<ExhibitCode label="Structure">

```text
MapMarker               map-marker
└─ preview              map-marker-preview         (while open, portalled)
   ├─ image             map-marker-image
   ├─ meta              map-marker-meta
   ├─ title             map-marker-title
   ├─ description       map-marker-description
   └─ content           map-marker-content         (your children)
```

</ExhibitCode>

## Usage

  guidelines={[

### Actions in the card

Children go under the other fields, for actions such as directions or saving
the place. The card stays open until you close it, so it can hold them.

<Exhibit of="map-marker.CustomContent" description="Click the dot to see the buttons.">
<ExhibitCode>

```tsx
<MapMarker label={place.name} title={place.name} description={place.summary}>
  <Button size="sm">Directions</Button>
  <Button size="sm" variant="outline">
    Save
  </Button>
</MapMarker>
```

</ExhibitCode>
</Exhibit>

### With a list beside the map

`open` and `onOpenChange` let a list choose the open marker. Picking a row
opens its card; opening a marker selects its row.

<Exhibit of="map-marker.Controlled" description="Pick a place, or click a dot.">
<ExhibitCode>

```tsx
const [openId, setOpenId] = useState<string | null>(null)

<MapMarker
  label={place.name}
  title={place.name}
  open={openId === place.id}
  onOpenChange={(open) => setOpenId(open ? place.id : null)}
/>
```

</ExhibitCode>
</Exhibit>

## Accessibility

| Key                              | Does                                                 |
| -------------------------------- | ---------------------------------------------------- |
| <Kbd>Tab</Kbd>                   | Moves between the markers                            |
| <Kbd>Space</Kbd> or <Kbd>↵</Kbd> | Opens the preview and moves focus into it            |
| <Kbd>Esc</Kbd>                   | Closes the preview and puts focus back on the marker |
