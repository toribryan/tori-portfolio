A diagram of a hub and the tools wired into it, for the top of a card or a
feature section. Live routes pulse, idle ones dim, and the hub can open a
preview on hover.

<Exhibit
  of="integration-visual.Default"
  title="Integration visual"
  description="Four tools in the corners, pulsing in. Hover or focus the snail for the last sync."
>
<ExhibitCode label="Install">

```bash
npx shadcn@latest add https://fibo.toribryan.com/r/integration-visual.json
```

It installs the `motion` package with it, for the pulses and the halo.

</ExhibitCode>
<ExhibitCode label="Usage">

```tsx
import { DatabaseIcon, MailIcon } from "lucide-react"

import { IntegrationVisual } from "@/components/ui/integration-visual"

export function ConnectedTools() {
  return (
    <IntegrationVisual
      label="Connected tools"
      items={[
        { title: "Database", icon: <DatabaseIcon /> },
        { title: "Email", icon: <MailIcon />, status: "idle" },
      ]}
    />
  )
}
```

Items fill the layout's slots in order, and any past its limit are left out.
Each `title` names its tile for screen readers.

</ExhibitCode>
<ExhibitCode label="Props">

| Prop          | Type                                           | Default          | Description                                                                                                                                                                                            |
| ------------- | ---------------------------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `items`       | `IntegrationItem[]`                            |                  | The tools wired into the hub.                                                                                                                                                                          |
| `center`      | `React.ReactNode`                              | A snail icon     | What names the hub. An icon element sits in a square face; a string or number is set as text and the face widens to fit. Defaults to a snail, for syncs that take their time.                          |
| `preview`     | `React.ReactNode \| IntegrationPreviewMedia`   |                  | Shown above the hub while it is hovered or focused, for looking at only. Pass any content, or `{ src, alt }` for an image, an animated image, or a video (`.mp4`, `.webm`) that plays muted on a loop. |
| `layout`      | `"corners" \| "orbit" \| "sides"`              | `"corners"`      | `corners` holds up to four, `orbit` and `sides` up to eight. Items past the limit are not drawn.                                                                                                       |
| `background`  | `"dots" \| "grid" \| "none"`                   | `"dots"`         | The plate behind the diagram.                                                                                                                                                                          |
| `routes`      | `"solid" \| "dashed"`                          | `"solid"`        | Route stroke.                                                                                                                                                                                          |
| `pulse`       | `"inward" \| "outward" \| "through" \| "none"` | `"inward"`       | Which way the pulse travels along each active route. `through` runs left to right, into the hub from the left and out of it on the right, so `sides` reads as a pipeline.                              |
| `size`        | `"sm" \| "default" \| "lg"`                    | `"default"`      | Scales the tiles and the hub.                                                                                                                                                                          |
| `halo`        | `boolean`                                      | `true`           | A slow ring breathing out from the hub.                                                                                                                                                                |
| `label`       | `string`                                       | `"Integrations"` | Accessible name for the diagram.                                                                                                                                                                       |
| `centerLabel` | `string`                                       |                  | Accessible name for the hub, which becomes a button when there's a preview. Defaults to `center` when that's text, otherwise to `label`.                                                               |

It also takes the props of a `div`, except `children`.

```ts
type IntegrationItem = {
  title: string
  icon: React.ReactNode
  status?: "active" | "idle"
  side?: "in" | "out" // sides layout only
}

type IntegrationPreviewMedia = {
  src: string
  alt?: string
  aspectRatio?: number | string // defaults to "16 / 9"
}
```

</ExhibitCode>
</Exhibit>

## Anatomy

A plate of dots, a hub in the middle, and a tile for each tool, joined to the
hub by a route. Pulses travel along live routes, and a halo breathes out from
the hub.

<Exhibit
  of="integration-visual.Anatomy"
  title="The diagram"
  description="Four tools in the corners, all live."
>
<ExhibitCode label="Structure">

```text
IntegrationVisual        integration-visual
├─ plate                 dots or grid, decorative
├─ routes                decorative
│  ├─ track              one per tool
│  └─ pulse              one per live tool
├─ item                  integration-visual-item
├─ hub                   integration-visual-hub
│  ├─ face               integration-visual-hub-face
│  └─ halo               decorative
└─ preview               integration-visual-preview  (while open)
```

</ExhibitCode>

### Idle tools

A tool that isn't connected yet keeps its tile and route, dimmed, with no
pulse. The diagram then shows what's possible as well as what's live.

  { title: "Calendar", icon: <CalendarIcon />, status: "idle" },

ring breathing out from the hub. Either can be turned off, and both stop for

<Tip>
  The preview is for looking at: nobody can reach a link or button inside it
  from the keyboard, so link out from the card around the diagram instead.
</Tip>

## Accessibility

It's a picture, so it's named rather than operated. The only stop for the
keyboard is the hub, and only when it has a preview.

<UsageGuidelines
  guidelines={[
    "A screen reader hears one named group, Integrations unless you name it for what it shows, then each tool by its name, with idle added for idle ones.",
    "The plate, routes, pulses and halo are decoration and are hidden from assistive technology.",
    "With a preview, the hub is a button named after the text in the hub, or the diagram's name. Focusing it opens the preview the same way hovering does, the preview describes it, and Escape closes it.",
    "For people who ask for reduced motion, the pulses and halo stop, tiles appear without springing in, the preview fades in place, and a preview video waits on its first frame.",
    "If the diagram only decorates a card whose text says the same thing, a screen reader still reads the tool names. Give it a name that adds to the card rather than repeats it.",
  ]}
