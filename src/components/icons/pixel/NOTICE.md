# Nucleo Pixel

These components are copied from the Nucleo Pixel React package (v1.4.0), one
file per icon actually used on the site. Regenerate by copying the component
from the Nucleo install and adding `shapeRendering="crispEdges"` to its `<svg>`,
which keeps the 2px geometry on the device grid at the 16px and 20px sizes this
site renders icons at.

The family is outline only. There is no glyph/solid fill, so an icon cannot
switch to a filled variant for a selected state.
